Help & Documentation

Everything you need to understand and use Helpdesk.

Tickets

  • Create new tickets from the Tickets menu.
  • Edit ticket details, assign users, update status.
  • Use the autosave feature — changes save automatically every 5 seconds.
  • Cases tab allows time logging with automatic 15‑minute rounding.

Messenger

  • Select a contact to open or create a conversation.
  • Messages update automatically every 2 seconds.
  • Unread messages highlight contacts in yellow.

User Management

  • Admins can manage users in the Admin Panel.
  • Permissions control access to Tickets and Messenger.

General

  • All pages use CSRF protection.
  • Bootstrap is used for styling.
  • Cloudinary handles media storage.
